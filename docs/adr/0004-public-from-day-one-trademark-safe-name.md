# Public from day one, with no "CSSLP" in the name

The Program is developed in a public GitHub repository from the first commit. It is named AppSec Ascent and described as "an unofficial study companion for the ISC2 CSSLP® exam".

CSSLP is a registered ISC2 certification mark, so:
- it appears only in plain text, together with ISC2's notice and a non-affiliation disclaimer
- it never appears in names, identifiers or logos
- all questions are original, never recalled from the exam

Code is licensed MIT. Content is licensed CC BY-NC-SA 4.0, which stops exam-prep resellers from repackaging it.

Keeping the repo public is also what makes CodeQL, secret scanning, push protection and artifact attestations free for the DevSecOps Labs. AI-DLC process records contain personal details, so they are excluded from this repository and backed up to a separate private one.

## Considered Options
- **Private until the user passes.** Rejected: it loses the free GitHub security features the Labs rely on.
- **"CSSLP" in the product name, with ISC2's written permission.** Rejected: slow, uncertain and unnecessary.
- **CC BY-SA 4.0 for content.** Rejected: it would allow commercial resale.
