# AI Lens is exam material, woven into every Domain

The CSSLP exam outline (effective 2023-09-15) never mentions AI, yet every Domain in the Program has an AI Lens. We treat that AI Lens as exam material rather than enrichment.

The reason is ISC2's *Exam Guidance for Artificial Intelligence* (dated 2026-09-01; the CSSLP section is on pp. 18–20). It maps AI topics into all eight CSSLP domains:

| Domain | AI topics |
|---|---|
| D1 | data poisoning and model inversion |
| D2 | MLSecOps and AI coding assistants |
| D3 | chatbot abuse cases |
| D4 | Zero Trust around vector databases |
| D5 | coding that accounts for prompt injection |
| D6 | testing models for evasion, drift and bias |
| D7 | monitoring for drift and adversarial attacks |
| D8 | AI-BOMs |

Weaving AI into each Domain therefore follows the exam rather than drifting from it. Hands-on adversarial ML that goes beyond exam depth lives in optional Deep Dives.

## Considered Options
- **A separate ninth "AI track" after the eight Domains.** Rejected. ISC2 integrates AI domain by domain. A separate track would also schedule exam-relevant material after the Boss Fights that test it.
