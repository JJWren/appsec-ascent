# Contributing to AppSec Ascent

Thank you for helping make AppSec Ascent accurate and useful.

## During Season 1: issues only
Season 1 is still being built. Until it's complete:
- **Issues are welcome**, especially Content Bugs: anything in the Curriculum that is wrong, unclear or badly cited.
- **Pull requests are not being accepted yet.** They open after Season 1 ships, and this page will say so when they do.

## Reporting a Content Bug
Use the **Content Bug** issue template. Include:
- the **item ID** (for example `q-4.4`, `lab-d5-01` or `dlv-d3-01`), which is shown by the Engine and at the top of every file
- the **citation ID** you believe is wrong or missing (for example `c2`)
- what is wrong, and a **free, authoritative source** that supports the correction

Learners using the Engine can run `ascent bug` to open a prefilled issue.

## Never post exam content
AppSec Ascent contains **no ISC2 exam questions**. Every practice question is original and is written from ISC2's public exam outline.
- Never post exam-recalled content: questions, answers or close paraphrases from a real exam. That would breach the exam's non-disclosure agreement.
- Issues or comments that contain exam-recalled material are removed.

## Spoilers
Labs, fixes, Flags, reference answers and the Question Bank are **Sealed**, which means they are shipped encrypted. Please don't post solutions in issues. Report the problem by item ID instead.
